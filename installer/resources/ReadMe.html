Before installing

This is a development version for editing isolated, single-voice recordings.

Automatic mode tunes to a key and scale. Note editor mode captures pitches while the original audio plays, then lets you move notes and replay the same source region.

Processing latency is approximately 128 ms. This version is intended for playback editing rather than live vocal monitoring.

The plug-ins install for all users in the standard macOS audio plug-in folders. Installation requires administrator authorization. Documentation, license information and corresponding source are installed in /Library/Application Support/Pitch Workbench.

If you installed an older prototype in your personal Library/Audio/Plug-Ins folder, move that older copy aside first to avoid duplicate plug-ins.
